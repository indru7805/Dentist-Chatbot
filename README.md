## How It Works
1. The patient sends a message from the chat page.
2. The server adds a system prompt that sets the bot's role as SmileCare's assistant.
3. The message and prompt go to the Groq API, and the reply appears in the chat.

## Getting Started
1. Clone the repository
   `git clone https://github.com/indru7805/Dentist-Chatbot.git`
2. Install dependencies
   `pip install -r requirements.txt`
3. Set your Groq API key (get one at console.groq.com)
   `export GROQ_API_KEY="your-key-here"`
4. Run the app
   `python app.py` [confirm the file name]
5. Open `http://localhost:5000`
